# iSpaceDoc 项目结构分析

## 项目概览

**项目名称：** iSpaceDoc 爱思文档开源版  
**版本：** v0.9.6  
**项目类型：** Django Web应用  
**主要语言：** Python, JavaScript, HTML, CSS  
**开源协议：** GPL-3.0  

## 目录结构总览

```
iSpaceDoc/
├── iSpaceDoc/                     # Django项目主配置目录
│   ├── __init__.py
│   ├── settings.py           # 核心配置文件
│   ├── urls.py              # 主路由配置
│   └── wsgi.py              # WSGI配置
├── app_admin/               # 后台管理模块
├── app_api/                 # API接口模块
├── app_doc/                 # 文档管理核心模块
├── config/                  # 配置文件目录
│   ├── config.ini          # 应用配置文件
│   └── uwsgi.ini           # uWSGI配置
├── static/                  # 静态资源文件
├── template/                # Django模板文件
├── media/                   # 媒体文件上传目录
├── locale/                  # 国际化文件
├── log/                     # 日志文件目录
├── requirements.txt         # Python依赖列表
├── manage.py               # Django管理脚本
├── docker-compose.yml      # Docker Compose配置
└── Dockerfile              # Docker镜像构建文件
```

## 核心应用模块详解

### 1. app_admin - 后台管理模块

**主要功能：**
- 系统设置管理
- 用户管理
- 文集权限管理
- 注册邀请码管理
- 站点配置管理

**核心文件：**
- `models.py` - 系统设置、用户选项、邮件验证码模型
- `views.py` - 后台管理视图逻辑
- `middleware/` - 中间件（登录验证、语言强制）

### 2. app_doc - 文档管理核心模块

**主要功能：**
- 文档CRUD操作
- 文集管理
- 文档协作
- 全文搜索
- 文档导入导出
- 文档历史版本管理

**核心模型：**
- `Project` - 文集模型（权限控制、水印配置）
- `Doc` - 文档模型（支持多种编辑器）
- `ProjectCollaborator` - 协作者管理
- `DocHistory` - 文档历史版本
- `Attachment` - 附件管理

**核心文件：**
- `models.py` - 数据模型定义
- `views.py` - 文档业务逻辑
- `search/` - 全文搜索功能
- `import_utils.py` - 文档导入工具

### 3. app_api - API接口模块

**主要功能：**
- RESTful API接口
- Token认证
- 第三方集成接口

**特性：**
- 基于Django REST Framework
- 支持用户Token API访问
- 跨域请求支持（CORS）

## 数据模型关系

### 核心实体关系

```
User (Django内置用户)
├── Project (文集)
│   ├── Doc (文档)
│   │   ├── DocHistory (历史版本)
│   │   └── DocTag (标签)
│   ├── ProjectCollaborator (协作者)
│   └── ProjectToc (目录结构)
├── Image (图片)
├── Attachment (附件)
└── UserOptions (用户设置)
```

### 权限系统

**文集权限级别：**
- 0: 公开
- 1: 私密
- 2: 指定用户可见
- 3: 访问码可见

**协作权限级别：**
- 0: 可新建、修改删除自己的文档
- 1: 可新建、删除自己的、修改所有文档
