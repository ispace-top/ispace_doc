# iSpaceDoc 爱思文档开源版 - 项目说明文档

## 项目简介

iSpaceDoc 是一个基于 Python Django 框架开发的在线文档管理系统，专为个人和中小型团队提供私有化的云文档、云笔记和知识管理解决方案。

### 核心定位
- **私有化部署的语雀** - 提供类似语雀的在线文档编辑体验
- **可在线编辑的GitBook** - 支持多种格式文档的在线编辑和发布
- **团队知识管理平台** - 支持多用户协作和权限管理

## 主要特性

### 📚 文档管理系统
- **多编辑器支持**：Editor.md、Vditor、iceEditor三种编辑器
- **丰富的文档类型**：文本文档、表格文档、富文本文档
- **文档组织**：支持文集、文档层级结构管理
- **版本控制**：文档历史版本管理和对比
- **模板系统**：可创建和使用文档模板

### 🔐 权限与协作
- **四级权限控制**：
  - 公开：所有人可访问
  - 私密：仅创建者可访问
  - 指定用户：特定用户可访问
  - 访问码：输入访问码可访问
- **协作功能**：支持多人协作编辑
- **用户管理**：完善的用户注册、登录、权限管理

### ⚙️ 系统管理
- **站点配置**：支持自定义站点信息、SEO配置
- **用户管理**：用户注册控制、邀请码管理
- **资源管理**：图片、附件统一管理
- **数据导出**：支持PDF、ePub、Word等格式导出

### 🔍 搜索与导航
- **全文搜索**：基于Whoosh的高效全文搜索
- **智能导航**：三级目录结构，文档大纲自动生成
- **标签系统**：文档标签分类和关联
- **站点地图**：SEO友好的sitemap生成

## 部署方案

### 快速部署
```bash
# Docker Compose 一键部署
git clone https://gitee.com/zmister/mrdoc-install.git
cd mrdoc-install
chmod +x docker-install.sh
./docker-install.sh
```

### 开发环境
```bash
# 安装依赖
pip install -r requirements.txt

# 数据库迁移
python manage.py migrate

# 创建超级用户
python manage.py createsuperuser

# 启动开发服务器
python manage.py runserver
```

### 生产环境
- 支持Docker容器化部署
- 支持传统Linux服务器部署
- 提供uWSGI配置文件
- 支持Nginx反向代理
