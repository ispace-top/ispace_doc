# 预存错误处理决议

> **参与角色**：产品经理 · RD 开发 · QA 测试  
> **分析日期**：2026-06-03  

---

## 发现的三类预存错误

### 1. 🔴 测试用例 19 个 ERROR — `Project` 模型已删除

**故障现象**：
```
NameError: name 'Project' is not defined
tests_api.py L207/L379/L434/L650
```

**根因分析（RD）**：  
`Project` 模型在迁移 0054 中已删除（数据已展平到 `Doc` 表）。但 `tests_api.py` 中 `SecurityAPITests` 和部分 `DocumentAPITests` 仍在 `setUp()` 中引用 `Project.objects.create()`。该模型类已不存在于 `models.py` 的 `__all__` 中，且未被 `from models import *` 导入。

**影响评估（QA）**：  
受影响 19 个测试用例，覆盖文档 CRUD、权限校验、安全防护三个测试类。这些测试无法验证对应功能是否正确。

**产品决策**：  
修复。这些测试覆盖的是**核心功能**（文档 CRUD、权限、安全），虽然迁移后 Project→Doc 的转换是正确的，但测试需要跟上代码演进，否则后续改动无法通过测试发现回归。

**修复方案（RD）**：  
将 `setUp()` 中的 `Project.objects.create(...)` 替换为 `Doc.objects.create(...)`，并将 `self.project.pk` 引用同步更新为 `self.doc.pk`，旧版双参数 URL `/pages/{proj_id}/{doc_id}/` 改为新版 `/pages/{doc_id}/`。涉及 4 个测试类的 setUp 和约 20 处引用。预估 1h。

### 2. 🟡 测试用例 2 个 FAIL — 通知 API 响应格式变更

**故障现象**：
```
AssertionError: None is not true
test_notification_list / test_unread_count
测试代码: self.assertTrue(data.get('status'))
实际响应: {"code": 0, "data": {...}, "message": "..."}
```

**根因分析（RD）**：  
通知 API 已从旧格式 `{"status": True, "data": ...}` 迁移到统一格式 `{"code": 0, "data": ...}`（`code: 0 = 成功`）。测试代码未同步更新。

**影响评估（QA）**：  
受影响 2 个测试，仅涉及通知列表查询和未读数查询，覆盖最基本的 API 连通性验证。

**产品决策**：  
建议修复。虽然功能无虞，但自动化测试的目的是守护质量基线，测试本身需要与 API 契约保持一致。

**修复方案（RD）**：  
将 `self.assertTrue(data.get('status'))` 改为 `self.assertEqual(data.get('code'), 0)`。2 行修改，预估 5 分钟。

### 3. 🟢 控制台 JS 错误 — `_ is not defined` + `SyntaxError`

**故障现象**：
```
ReferenceError: _ is not defined  (underscore.js 未加载)
SyntaxError: Invalid or unexpected token
```

**根因分析（RD）**：  
- `_ is not defined`：前端 `frontend/static/markdown-ext/sequence/sequence-diagram.min.js` 依赖于 underscore.js，但模板中未前置加载 underscore。sequence-diagram bundle 自身不包含 underscore 运行时。
- `SyntaxError`：经排查，`inline_editor.html` 中某处存在模板渲染后的非法 JS 字符。该错误在本次修改前即存在（可通过 `git stash` 验证）。

**影响评估（QA）**：  
- `_ is not defined`：实际不影响用户体验——sequence diagram 渲染函数 `processCustomCodeBlocks` 会先检查 `typeof Diagram !== 'undefined'`，若 underscore 未定义则 Diagram 也为 undefined，渲染逻辑被跳过，仅控制台报错。
- `SyntaxError`：无可见功能影响。
- **风险极低**：这两个错误均不影响核心功能，仅在开发者工具中可见。

**产品决策**：  
**不修复，记录在案。** 理由：
1. 属于存量技术债务，非本次需求变更引入
2. 对用户无感知（功能正常运行）
3. 修复需改动第三方库加载顺序，有引入新问题的风险
4. 建议在后续大版本重构时一并治理
