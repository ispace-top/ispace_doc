# 📝 Markdown 基础与 Callout 提示块

>i **本章节** 介绍 Markdown 基础语法和 Callout 彩色提示块。每个示例下方展示实际渲染效果。

## 1. 标题 (H1-H6)

使用 `#` 号，数量对应级别。

**使用方式：**

```markdown
# 一级标题
## 二级标题
### 三级标题
```

**渲染效果：**

# 一级标题
## 二级标题
### 三级标题

## 2. 文本样式

**使用方式：**

```markdown
**粗体** *斜体* ~~删除线~~ `代码`
```

**渲染效果：** **粗体** *斜体* ~~删除线~~ `代码`

## 3. 列表

### 3.1 无序列表

**使用方式：**

```markdown
- 项目 A
- 项目 B
  - 子项目 B1
  - 子项目 B2
```

**渲染效果：**

- 项目 A
- 项目 B
  - 子项目 B1
  - 子项目 B2

### 3.2 有序列表

**使用方式：**

```markdown
1. 第一步
2. 第二步
3. 第三步
```

**渲染效果：**

1. 第一步
2. 第二步
3. 第三步

### 3.3 任务列表

**使用方式：**

```markdown
- [ ] 待办事项
- [x] 已完成事项
```

**渲染效果：**

- [ ] 待办事项
- [x] 已完成事项

## 4. 引用与嵌套

**使用方式：**

```markdown
> 一级引用
>> 二级引用
>>> 三级引用
```

**渲染效果：**

> 一级引用
>> 二级引用
>>> 三级引用

## 5. 链接与图片

**使用方式：**

```markdown
[链接文字](https://example.com)
![图片描述](/media/logos/site_logo.png)
```

## 6. Callout 提示块

爱思文档支持 4 种彩色提示块，在引用语法 `>` 后添加类型标识。

| 语法 | 类型 | 用途 |
|------|------|------|
| `>i` | info 信息 | 一般性说明 |
| `>w` | warning 警告 | 提醒注意风险 |
| `>e` | danger 错误 | 严重问题 |
| `>s` | success 成功 | 正面消息 |

### 6.1 信息提示

**使用方式：** `>i **提示** — 说明文字`

**渲染效果：**

>i **提示** — 这是一条信息提示，用于展示一般性说明。

### 6.2 警告提示

**使用方式：** `>w **注意** — 警告文字`

**渲染效果：**

>w **注意** — 请谨慎执行此操作，可能影响系统性能。

### 6.3 错误提示

**使用方式：** `>e **错误** — 错误文字`

**渲染效果：**

>e **错误** — 数据库连接失败，请检查网络配置。

### 6.4 成功提示

**使用方式：** `>s **完成** — 成功文字`

**渲染效果：**

>s **完成** — 任务已成功执行，所有数据已保存。
