# 📝 Markdown 基础与 Callout 提示块

>i **本章节** 介绍 Markdown 基础语法和 Callout 彩色提示块。每个示例下方展示实际渲染效果。

## 1. 标题 (H1-H6)

使用 `#` 号，数量对应级别。

**使用方式：**

```markdown
# 一级标题
## 二级标题
### 三级标题
```

**渲染效果：**

# 一级标题
## 二级标题
### 三级标题

## 2. 文本样式

**使用方式：** `**粗体** *斜体* ~~删除线~~ \`代码\``

**渲染效果：** **粗体** *斜体* ~~删除线~~ `代码`

## 3. 列表

无序：`- item` ；有序：`1. item` ；任务：`- [ ] todo`

## 4. 引用

```markdown
> 一级
>> 二级
```

> 一级
>> 二级

## 5. Callout 提示块

四种彩色提示块：`>i` / `>w` / `>e` / `>s`

### 5.1 信息提示

**使用方式：** `>i **提示** — 说明文字`

**渲染效果：**

>i **提示** — 这是一条信息提示，用于展示一般性说明。

### 5.2 警告提示

**使用方式：** `>w **注意** — 警告文字`

**渲染效果：**

>w **注意** — 请谨慎执行此操作，可能影响系统性能。

### 5.3 错误提示

**使用方式：** `>e **错误** — 错误文字`

**渲染效果：**

>e **错误** — 数据库连接失败，请检查网络配置。

### 5.4 成功提示

**使用方式：** `>s **完成** — 成功文字`

**渲染效果：**

>s **完成** — 任务已成功执行，所有数据已保存。
