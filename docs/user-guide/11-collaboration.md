# 💬 协作功能详解

>i **本章节** 介绍文档评论、划词评论、@提及、通知等协作功能。

## 1. 文档评论

点击底部"回复"展开评论框，支持多级嵌套回复（最多3层缩进）。

## 2. 划词评论 (Inline Comment)

1. **选中正文文字** → 弹出浮动工具栏
2. 点击**"评论"**创建锚定评论
3. 点击**"高亮"**添加黄色背景标记
4. 高亮文字显示评论数量角标

## 3. @提及功能

在编辑器和评论中输入 `@` 触发用户搜索：
- 支持文档正文、评论、划词评论三种场景
- 被 @ 用户收到站内通知
- 支持自己 @ 自己（备忘）

## 4. 通知系统

- Header 铃铛图标 → 下拉面板
- 显示未读通知（头像+标题+摘要+时间）
- "全部已读"批量标记
- 点击跳转对应文档

## 5. 用户信息卡片

悬停头像或用户名 300ms → 弹出卡片：
- 显示头像、姓名、性别、组织、简介
- 始终在触发元素正上方
- 纯淡入动画 150ms
