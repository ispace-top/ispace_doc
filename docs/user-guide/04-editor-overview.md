## 编辑器工具栏

| 按钮 | 功能 | 快捷键 |
|------|------|--------|
| Markdown | 模式切换 | - |
| 标题 | H1-H6 | Ctrl+H |
| 粗体 | **Bold** | Ctrl+B |
| 斜体 | *Italic* | Ctrl+I |
| 删除线 | ~~Strike~~ | Ctrl+D |
| 代码块 | 围栏代码 | Ctrl+U |
| 链接 | [text](url) | Ctrl+K |
| 表格 | 插入表格 | - |
| 思维导图 | mindmap | - |
| 流程图 | flowchart.js | - |
| 图表 | ECharts | - |
| 撤销/重做 | Undo/Redo | Ctrl+Z/Y |
