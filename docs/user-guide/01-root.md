# 📖 爱思文档用户指南

>i **欢迎使用爱思文档** — 一款功能强大的在线文档管理系统，支持 Markdown 编辑、多级文档树、划词评论、图表渲染、权限管理等丰富特性。

## 🌟 系统特性一览

| 分类 | 功能 |
|------|------|
| 📝 文档编辑 | Markdown IR 所见即所得、Vditor 编辑器、多种图表组件 |
| 📊 图表渲染 | ECharts、思维导图、流程图、时序图、PlantUML、Graphviz、五线谱 |
| 🔢 数学公式 | KaTeX 行内公式与块级公式 |
| 💬 协作 | 评论、划词评论、@提及、通知 |
| 🔐 权限 | 文档级权限、用户/分组/组织三线授权 |
| 🌳 文档树 | 多级层级、拖拽排序、手风琴展开 |
| 🔍 搜索 | Whoosh 全文检索 + jieba 中文分词 |
| 🔔 通知 | 站内+邮件+企业微信+钉钉 |
| 🎨 主题 | 亮色/暗色模式 |

## 🚀 快速入门

1. **创建文档** — 右键侧边栏 → 新建文档
2. **编辑内容** — 使用 Markdown 或工具栏插入图表
3. **发布文档** — 点击"发布"
4. **组织文档** — 右键文档 → 新建子文档

## 📚 详细指南

- **系统安装配置** — 环境要求、Docker 部署、数据库配置
- **管理员后台** — 用户管理、系统设置、审计日志
- **文档编辑指南** — 覆盖全部编辑组件，含代码示例与渲染效果
