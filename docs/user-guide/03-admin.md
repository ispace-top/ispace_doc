# ⚙️ 管理员后台设置管理

>i **路径**：`/admin/dashboard/`，仅超级管理员可访问。

## 1. 仪表盘

系统资源监控（CPU/内存/磁盘）、站点统计数据、最近动态。

## 2. 用户管理

- 用户列表：分页、搜索、角色标签
- 创建/编辑：用户名、邮箱、密码、超管开关
- 删除：确认后移除

## 3. 系统设置

| 设置项 | 说明 |
|--------|------|
| 站点名称 | 标题和导航栏 |
| ICP 备案号 | 页脚 |
| 关闭注册 | 禁止新用户 |
| 全站强制登录 | 所有页面需登录 |
| 邮件 SMTP | 主机/端口/密码/SSL |

## 4. 认证配置

支持 OIDC / 企业微信 / 钉钉 / LDAP，可连接测试。

## 5. 系统运维

- 数据备份（JSON ZIP）
- 缓存清理
- 搜索索引重建
- 版本检查（GitHub API）

## 6. 审计监控

审计日志、登录记录、系统日志、健康评分（0-100）。
