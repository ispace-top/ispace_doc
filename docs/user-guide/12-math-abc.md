# 🔢 数学公式与五线谱

>i **在编辑器中输入数学公式和五线谱。行内公式用 `$...$` 包裹，块级公式用 `$$...$$` 包裹，乐谱用 ```abc ``` 代码块。**

## 1. 行内公式

在正文中直接使用 `$...$` 嵌入公式：

- `$E=mc^2$` → 渲染为 $E=mc^2$
- `$a^2+b^2=c^2$` → 渲染为 $a^2+b^2=c^2$
- `$\frac{a}{b}$` → 渲染为 $\frac{a}{b}$

## 2. 块级公式

使用 `$$...$$` 包裹，居中显示。

**使用方式：**

```text
$$
x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}
$$
```

**渲染效果：**

$$
x = \frac{-b \pm \sqrt{b^2-4ac}}{2a}
$$

## 3. 常用符号速查

| 输入 | 效果 | 说明 |
|------|------|------|
| `$x^2$` | $x^2$ | 上标 |
| `$x_1$` | $x_1$ | 下标 |
| `$\frac{a}{b}$` | $\frac{a}{b}$ | 分数 |
| `$\sqrt{x}$` | $\sqrt{x}$ | 平方根 |
| `$\pi$` | $\pi$ | 希腊字母 |
| `$\infty$` | $\infty$ | 无穷 |
| `$\pm$` | $\pm$ | 正负号 |
| `$\times$` | $\times$ | 乘号 |
| `$\sum$` | $\sum$ | 求和 |
| `$\int$` | $\int$ | 积分 |

## 4. 五线谱 (abcjs)

使用 ```abc ``` 代码块输入 ABC 记谱法。ABC 是一种纯文本音乐记谱格式。

**使用方式：在编辑器中输入以下内容，用 ```abc ``` 围栏包裹**

```text
X:1
T:小星星
M:4/4
L:1/4
K:C
C C G G | A A G2 | F F E E | D D C2 |
```

**渲染效果：**

```abc
X:1
T:小星星
M:4/4
L:1/4
K:C
C C G G | A A G2 | F F E E | D D C2 |
```

**ABC 标记说明：**

| 标记 | 含义 | 示例 |
|------|------|------|
| `X:N` | 乐曲编号 | `X:1` |
| `T:标题` | 乐曲名称 | `T:小星星` |
| `M:拍号` | 节拍 | `M:4/4` |
| `L:时值` | 默认音符时值 | `L:1/4` |
| `K:调号` | 调性 | `K:C` (C大调) |
| `CDEFGAB` | 音名 | C D E F G A B |
| `c d e f g a b` | 高八度 | 小写字母高一八度 |
| `|` | 小节线 | 分隔小节 |
| `数字` | 时值 | `C2` = C音两拍 |
